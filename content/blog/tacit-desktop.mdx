# Try Tacit — A new desktop for linux that is Modern and is easy to use. 

> You don't have to learn terminal or use dated ui if you are new to linux anymore >:

Me, you and alot of other users have tried the desktop in linux and we all have to learn to use terminal to fix something and use dated ui to use. Now there is option to customize but a general user just wants to leave microslop then plug and play linux instead of spening hours customizing before.

Now if you want to then you can learn customizing that is upto you but the goal of Tacit is to provide you a good interface and terminal less work

Now the main thing is built on Hyprland with QML so a lot of people might argue that this is just a fancy promotion for a rice but Tacit is completely unique in following features.

## Features of Tacit
### 1. Native daily use apps
Fresh installation of tacit provides you with modern looking apps 
- File manager
- Browser
- AI agent with multiple provider setup
- Image and Video Player
- Settings app
- Code editor
- App store

All of these apps have aesthetically pleasing ui and coherent design so your desktop looks as a whole.
### 2. Multiple widgets and desktop icons
A lot of hyprland desktops do not gives desktop icons but here at Tacit we know that non technical users have a habit of using them so we provided them.
### 3. Update system
You can update your system directly from your settings app and don't have to touch terminal.
### 4. Terminal less interface
Tacit provides you majorly everything that you might need for a terminal less usage of your desktop. We are also constantly releasing new features which users ask in our discord server.
### 5. Unified settings app
You do not need to write commands in terminal to change something or need to edit config files to change keybinds/shortcuts, you can do these directly from your settings app.
